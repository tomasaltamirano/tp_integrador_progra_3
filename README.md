## Acerca del Proyecto

Proyecto FullStack pensada para una vista de cliente y una vista de administrador.

- **Aplicación Frontend (Cliente):** Una interfaz web responsive diseñada para que los clientes puedan explorar un catálogo de productos, gestionar su carrito de compras y finalizar la operación emitiendo un ticket.
- **Aplicación Backend (Backoffice y API):**
  - Un servidor que provee una API REST en formato JSON para alimentar al frontend.
  - Un panel de administrador renderizado con vistas HTML mediante EJS. Este panel requiere autenticación y permite realizar el mantenimiento del sistema (Alta, Baja y Modificación de productos) y visualizar reportes.
